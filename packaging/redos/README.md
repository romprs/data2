# RPM-пакет для РЕД ОС / RHEL-совместимых систем

Системная установка «поставил один раз — появилось у всех пользователей»:
пакет кладёт оверлей в `/usr/share`, автозапуск — через
`/etc/xdg/autostart` (стандартный freedesktop-механизм, подхватывается
GNOME/KDE/XFCE/MATE и т.д. **для каждого пользователя автоматически**,
без ручного `systemctl --user enable` на каждой учётке), а прозрачность
и текст знака настраиваются **одним общим файлом**
`/etc/watermark-overlay/config.json` — правите его один раз, меняется
у всех, живьём, без перезапуска процессов.

## Установка

Скопируйте `dist/watermark-overlay-0.1.0-1.noarch.rpm` на целевую машину
и установите:

```bash
sudo dnf install ./watermark-overlay-0.1.0-1.noarch.rpm
```

(или `sudo rpm -ivh ./watermark-overlay-0.1.0-1.noarch.rpm`, если `dnf`
недоступен).

Пакет при установке (`%post`) сам проверит, есть ли `PyQt5`/`python-xlib`
в системе, и если нет — попробует поставить их через `pip` (нужен доступ
в интернет на момент установки). Если авто-установка зависимостей не
удалась (нет сети), пакет всё равно установится, но появится
предупреждение — тогда поставьте вручную:
```bash
sudo dnf install python3-qt5 python3-xlib
# или
sudo python3 -m pip install PyQt5 python-xlib
```

Дальше **никаких дополнительных действий не требуется** — при следующем
входе в графическую (X11) сессию у любого пользователя автоматически
запустится оверлей.

Чтобы применить сразу, без перезахода — каждый пользователь может
запустить вручную: `watermark-overlay &`.

## Настройка прозрачности для всех

```bash
sudo nano /etc/watermark-overlay/config.json
```

```json
{
  "text": "{user}",
  "opacity": 45,
  "font_size": 18,
  "angle": -30.0,
  "spacing": 80
}
```

Сохранили — у всех уже запущенных копий (у всех залогиненных
пользователей) прозрачность/текст обновятся в течение секунды, без
перезапуска. Подробнее про формат и `{user}`/`{host}`/`{time}` —
[`../../overlay/linux/README.md`](../../overlay/linux/README.md).

> Если пользователь создаст свой `~/.config/watermark-overlay/config.json`,
> он переопределит общий файл лично для себя (см. приоритет настроек в
> README оверлея) — это осознанная возможность, а не баг. Если нужно
> жёстко запретить пользователям это делать — потребуется доработка
> (whitelist/lock-флаг в общем конфиге), сейчас в прототипе её нет.

## Удаление

```bash
sudo dnf remove watermark-overlay
```

## Пересборка пакета из исходников

Нужен `rpmbuild` (пакет `rpm-build` на RED OS/RHEL/Fedora):

```bash
sudo dnf install -y rpm-build
bash build.sh
```

Результат: `dist/watermark-overlay-<версия>-<релиз>.noarch.rpm`.

## Что внутри пакета

| Путь на диске | Назначение |
|---|---|
| `/usr/share/watermark-overlay/watermark_overlay.py` | сам оверлей (копия [`overlay/linux/watermark_overlay.py`](../../overlay/linux/watermark_overlay.py)) |
| `/usr/bin/watermark-overlay` | обёртка для запуска |
| `/etc/xdg/autostart/watermark-overlay.desktop` | автозапуск для всех пользователей при входе в графическую сессию |
| `/etc/watermark-overlay/config.json` | общие настройки (помечен `%config(noreplace)` — при обновлении пакета ваши правки не затираются) |

## Ограничения (честно)

- Автозапуск и настройки — общие для всех, но это **не anti-tamper**:
  любой пользователь может закрыть окно процесса (`pkill
  watermark-overlay`) или удалить/переопределить конфиг для себя —
  полноценная защита от отключения (раздел 6 плана) в прототип не входит.
- Требует X11-сессию (не Wayland) — см. ограничения в
  [`overlay/linux/README.md`](../../overlay/linux/README.md).
- Печать этим пакетом не покрывается (отдельный модуль, Этап 2).
